# Vokabelkasten

Vokabelzettel mit dem iPhone fotografieren, Vokabelpaare automatisch erkennen lassen und schriftlich in beide Richtungen üben.

- App: https://stefesbau.github.io/vokabelkasten/
- Auf dem iPhone in Safari öffnen → „Teilen“ → „Zum Home-Bildschirm“.
- Die Texterkennung (Tesseract) läuft direkt auf dem Gerät, ohne Server und ohne Kosten.
- Listen und Lernstand werden nur auf dem jeweiligen Gerät gespeichert.
- Listen lassen sich per Link übernehmen: `…/vokabelkasten/#import=<Daten>`.

Dateien: `index.html` (App), `pair.js` (Zuordnung der Spalten), `sw.js` (Offline-Betrieb), `manifest.webmanifest` und Icons.
